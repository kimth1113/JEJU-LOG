# JEJU-LOG

제주 촬영 맥락을 사진과 AI 문구로 기록하는 포토부스 교육 프로젝트입니다.

- 제주 장소·촬영 정보와 사진을 연결한 사용자 흐름
- 사진 결과와 이야기·문구 생성 경험 구현
- 웹 화면과 이미지 처리 API 연동

## 이후 개발

촬영 경험과 적용 범위를 확장한 후속 프로젝트는 **[LIFELOG](https://github.com/kimth1113/LIFELOG)**입니다. 이 저장소는 초기 프로젝트의 소스와 개발 기록을 보관합니다.

소스는 `jeju_photo/`와 `jeju-log/`에 있습니다. 실행 환경과 의존성은 각 폴더의 설정 파일을 기준으로 확인합니다.
